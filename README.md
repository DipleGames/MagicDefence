# MagicDefence

세로형 모바일 화면을 위한 마법 디펜스 장면 프로토타입입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.
로컬 서버를 사용하려면 저장소 폴더에서 `python -m http.server 8080`을 실행하세요.

맵을 우클릭하면 마법사가 해당 방향을 바라보며 이동합니다. 장애물이 없는 초록색 평지 전체가 한 화면에 표시되며, 고정 카메라로 플레이합니다. 초록색 맵의 가장자리와 네 모서리까지 전체 영역을 이동할 수 있습니다. 화면 크기와 시점 회전에 맞춰 맵과 캐릭터가 UI 사이에 들어오도록 배율을 조정합니다. 모바일에서는 맵을 터치해 이동합니다. 이동 중 새 지점을 선택하면 목적지가 변경됩니다. 우클릭을 누른 채 마우스를 움직여 연속 이동 명령을 내릴 수 있습니다. 열린 공간에서 직선 이동하며, 캐릭터는 이동 방향으로 부드럽게 회전합니다.

마우스 좌클릭 또는 하단 마법 버튼으로 마법 파동을 발생시키며, 우측 상단 회전 버튼으로 시점을 바꿀 수 있습니다.

Canvas 2D에 3D 다각형 메시를 투영해 로우폴리 캐릭터와 초록색 평지을 그립니다.
현재는 장면 및 시각 효과 프로토타입으로, 적·전투·웨이브 진행은 구현되어 있지 않습니다.

## 이동 검증

`node tests/movement.cjs`로 직선 이동, 회전 보간, 장애물 우회, 목적지 변경 및 충돌 회귀 검증을 실행합니다.

`node tests/visibility.cjs`로 화면 크기 3종·시점 32개·캐릭터 방향 4종에서 맵 가장자리의 캐릭터 가시성, 바닥 그리기 순서, 고정 카메라 및 클릭 좌표를 검증합니다.

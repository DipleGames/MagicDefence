# MagicDefence

세로형 모바일 화면을 위한 마법 디펜스 장면 프로토타입입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.
로컬 서버를 사용하려면 저장소 폴더에서 `python -m http.server 8080`을 실행하세요.

맵을 우클릭하면 해당 지점으로 마법사가 이동합니다. 모바일에서는 맵을 터치해 이동합니다. 이동 중 새 지점을 선택하면 목적지가 변경됩니다.

마우스 좌클릭 또는 하단 마법 버튼으로 마법 파동을 발생시키며, 우측 상단 회전 버튼으로 시점을 바꿀 수 있습니다.

Canvas 2D에 3D 다각형 메시를 투영해 로우폴리 캐릭터와 숲을 그립니다.
현재는 장면 및 시각 효과 프로토타입으로, 적·전투·웨이브 진행은 구현되어 있지 않습니다.

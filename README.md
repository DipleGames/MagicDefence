# MagicDefence

세로형 모바일 화면을 위한 마법 디펜스 장면 프로토타입입니다. 하늘에 떠 있는 황금빛 섬, 석판 타일 전투장과 작은 식물 장식으로 구성됩니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.
로컬 서버를 사용하려면 저장소 폴더에서 `python -m http.server 8080`을 실행하세요.

맵을 우클릭하면 마법사가 해당 방향을 바라보며 이동합니다. 이동 가능한 영역은 보이는 석판 전투장과 일치합니다. 이동 중 새 지점을 선택하거나 우클릭을 누른 채 마우스를 움직여 목적지를 변경할 수 있습니다.

모바일에서는 맵을 터치하거나 하단 조이스틱을 드래그해 이동합니다. 조이스틱에서 손을 떼면 멈춥니다. 마우스 좌클릭 또는 우측 마법 버튼으로 마법을 사용합니다. 우측 상단 회전 버튼은 시점을 변경하고, 좌측 상단 일시 정지 버튼은 이동과 입력을 정지합니다.

상단 레벨·경험치·재화는 UI 프로토타입의 초기 표시값입니다. 전투나 보상에 따른 증가는 아직 구현하지 않았습니다.

Canvas 2D에 3D 다각형 메시를 투영해 로우폴리 캐릭터와 석판 전투장을 그립니다.
현재는 장면 및 시각 효과 프로토타입으로, 적·전투·웨이브 진행은 구현되어 있지 않습니다.

## 이동 검증

`node tests/movement.cjs`로 직선 이동, 회전 보간, 장애물 우회, 목적지 변경 및 충돌 회귀 검증을 실행합니다.

`node tests/visibility.cjs`로 화면 크기 3종·시점 32개·캐릭터 방향 4종에서 맵 가장자리의 캐릭터 가시성, 바닥 그리기 순서, 고정 카메라 및 클릭 좌표를 검증합니다.
